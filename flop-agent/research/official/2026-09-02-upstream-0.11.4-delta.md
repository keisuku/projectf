## 3. Live E2E, this time against a running server

Session 2 rehearsed in-process (`TestClient`). This session ran upstream for real —
`uvicorn --app-dir src app:app` under Python 3.12.14 from `uv sync` — and drove it with
`flopdid.py --fetch` over HTTP using the RFC 8032 test key on a throwaway root:

1. `claim d-e2etest` → `HTTP 200 ok room-owners/d-e2etest 56B … signed by z6Mk…MMsw`
2. two `say` → 200 each; `GET /r/d-e2etest?format=json` returns `generation`, `first_seq`,
   `last_seq`, and per message `seq`, `ts`, `from`, `text`, `nonce`, `sig`
3. `GET /r/d-e2etest/export` → `application/x-ndjson`, header `x-room-generation: 1`,
   one JSON object per line with the same fields
4. unsigned `say` from a stranger → 403
5. every exported line re-verified offline: `didkey.verify(from, sig, f"{room}|{nonce}|{text}")`

The same server, bound to the container's non-loopback interface, was then used to
exercise the production write gate end to end (see `STATUS.md` § Verified 2026-09-02).
